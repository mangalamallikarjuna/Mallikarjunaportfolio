# Mangala Mallikarjuna - Portfolio Website

A professional portfolio website for Computer Science Engineering student Mangala Mallikarjuna.

## How to Use in Visual Studio Code

### Method 1: Simple Setup (Recommended)

1. **Create a new folder** on your computer called `mangala-portfolio`

2. **Open Visual Studio Code**

3. **Open the folder** in VS Code:
   - Click `File` → `Open Folder`
   - Select the `mangala-portfolio` folder you created

4. **Copy the files**:
   - The files `index.html`, `style.css`, and `main.js` are already created in this project
   - You can see them in the file explorer on the left side

5. **View the website**:
   - Right-click on `index.html` in the file explorer
   - Select "Open with Live Server" (if you have the Live Server extension)
   - OR simply double-click `index.html` to open it in your browser

### Method 2: Using Live Server Extension

1. **Install Live Server extension**:
   - Press `Ctrl+Shift+X` to open Extensions
   - Search for "Live Server" by Ritwick Dey
   - Click "Install"

2. **Start Live Server**:
   - Right-click on `index.html`
   - Select "Open with Live Server"
   - Your website will open automatically in the browser

### Method 3: Direct Browser Opening

1. **Navigate to your project folder** in File Explorer/Finder
2. **Double-click on `index.html`**
3. **The website will open** in your default browser
